🛒 智慧三农 — 农业综合服务电商平台

全栈开发 | 2026.02 - 2026.05

智慧三农是一个面向农户、农资商家及消费者的农业综合服务电商平台，提供农资采购、农产品销售、行业资讯等一站式服务。

项目概述

平台采用经典的四段式页面结构（顶部导航 + Banner + 分类入口 + 商品推荐），视觉清晰，功能分区明确，以绿色为主色调契合农业主题。

核心功能

模块 功能描述
三农商城 农资商品展示、分类浏览（种子种苗 / 化肥肥料 / 农药制剂 / 农机农具）、购物车、订单管理
三农资讯 农业政策、技术指导、市场行情等内容发布与浏览
用户中心 个人账户管理、订单查询、收货地址管理
商品推荐 首页推荐商品展示，包含商品图、价格、评分评论、加入购物车
搜索功能 支持关键词搜索商品与资讯

技术实现

  • 前端：基于 HTML5 + CSS3 + JavaScript 实现 30+ 页面开发，包含响应式适配、商品交易交互、购物车状态同步
  • 架构：封装请求工具，完成登录鉴权与 Token 管理
  • 后端：基于 Node.js + JSON Server 搭建轻量服务，设计商品、订单、用户等数据模型
  • 接口：开发 RESTful 接口实现数据增删改查，独立完成前后端联调与本地部署

页面亮点

  • Banner 营销区：渐变绿色背景搭配"农资优选购 · 助农促增收"标语，强化品牌信任感
  • 分类入口区：四类农资圆形图标导航，配色统一，便于快速识别
  • 商品卡片：标准化卡片布局，含缩略图、名称、价格、星级评分、评论数及购物车按钮
  • 浮动购物车：右下角悬浮按钮 + 数字角标，实时展示购物车商品数量
